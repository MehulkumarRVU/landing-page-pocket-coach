# PocketCoach by TrinariX — landing page

**index.html** is the finished site. It is fully self-contained (3D engine, font and code are inside it),
so you can double-click it to open, or upload this one file to Netlify, Vercel, GitHub Pages or any host.

## Editing
- Text and layout: `src/template.html` (all copy and CSS)
- 3D scenes and animation: `src/main.js` (three.js)
- Rebuild after editing: `npm install` once, then `npm run build` -> writes `dist/index.html`

## Before launch (from the content guide's checklist)
- Replace the `mailto:hello@trinarix.com` on the final "Get started" button with your real sign-up link or verified email
- Fill in Privacy policy / Terms links in the footer (currently `#`)
- Swap founder initials for approved photos
- Confirm which of the 9 training categories are live; remove any that aren't
- The hero/process angle readouts are an illustrative 3D demo, not real analysis output (the page says so)
